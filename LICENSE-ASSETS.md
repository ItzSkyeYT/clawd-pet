# Artwork: all rights reserved

The [MIT license](LICENSE) covers Clawd's code. It does not cover the artwork.

## What counts as artwork

- Everything in `sprites/`: the traced Clawd frames (`clawd.json`) and the hand-drawn
  extras (`extras.py`, `birthday.py`), such as the hats, props, umbrella, parachute and
  birthday party
- Everything in `docs/media/`: the GIFs and the screenshot in the README
- Anything drawn from those, such as the frames and icons the app renders

## What you can do without asking

- Download, install and run Clawd, and change your own copy, for yourself
- Fork this repository on GitHub to send pull requests
- Share screenshots and recordings of Clawd running, to show him off or review him

## Ask first for anything else

Any other use of the artwork needs my written permission for that specific use. That
includes:

- using it, or art based on it, in another app, game, website or project
- redistributing or repackaging it anywhere other than a GitHub fork of this repository
- selling anything that uses it

To ask, open an issue on this repository.

## Clawd belongs to Anthropic

Clawd is Anthropic's character, and the frames in `sprites/clawd.json` are traced from
Anthropic's official Clawd animations. Those aren't mine to license: for Clawd himself,
Anthropic's rights apply, and my permission only ever covers my own additions.
